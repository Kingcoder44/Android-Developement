# 🎵 MusicApp UI Advanced

A modern and interactive **Music App UI** built using **Jetpack Compose** in Android. This app features a sleek design with a **bottom navigation bar, navigation drawer, categorized music sections, and smooth UI animations**.

---

## 📱 Features

- 🎨 **Jetpack Compose UI** for a modern and declarative layout
- 🔄 **Bottom Navigation Bar** for quick access to Home, Browse, and Library
- 📂 **Navigation Drawer** for easy category selection
- 🏷 **Categorized Music Sections** (Romance, Hits, Lo-Fi, etc.)
- 🖼 **Card-based UI** with album covers and song previews
- 🌙 **Dark Mode & Theming Support**

---

## 📦 Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/your-username/MusicApp-UI-Advanced.git
   ```
2. **Open in Android Studio**
   - Open the project in **Android Studio**
   - Sync **Gradle dependencies**
3. **Build & Run the App**
   - Click on the **Run** button ▶️ in Android Studio or use the following command:
   ```sh
   ./gradlew build
   ```
4. **Install APK on Device**
   ```sh
   adb install app-release.apk
   ```
5. **Minimum Requirements**
   - Android **SDK 26+** (Oreo and above)
   - Kotlin **1.8+**
   - Jetpack Compose **Stable Release**
