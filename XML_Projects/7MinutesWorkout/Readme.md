# 🏋️‍♂️ 7-Minute Workout App  

A simple **7-minute workout** app designed to help users stay fit with quick and effective exercises. The app includes **9-11 exercises**, a **BMI calculator**, and a **history feature** to track progress.  

---

## 🚀 Features  

### 🔹 **Workout Sessions**  
- A set of **9-11 exercises**, each lasting a fixed duration.  
- Rest intervals between exercises.  
- Visual and audio cues for better engagement.  

### 📊 **BMI Calculator**  
- Calculates **Body Mass Index (BMI)** based on height and weight.  
- Provides BMI category (Underweight, Normal, Overweight, Obese).  

### 📜 **Workout History**  
- Tracks completed workout sessions.  
- Displays the date and time of previous workouts.  

### 🎨 **User-Friendly UI**  
- Built using **XML layouts** and **Activities**.  
- Easy navigation between workout, BMI calculator, and history screens.

## 🔧 How to Run the Project  

### ✅ Clone the Repository  
1. Open a terminal and run:  
   ```bash
   git clone https://github.com/Kingcoder44/Android-Developemnet/7-minute-workout-app.git
   cd 7-minute-workout-app
   ```
   
### ✅ Open in Android Studio  
2. Open the project in **Android Studio**.  
3. **Sync Gradle** and install dependencies.  
4. Run the app on an **emulator or physical device**.
